**ExitLens**
_Audit subscription cancellation friction --- with evidence,
transparency, and user control._

ExitLens is a tool designed to review subscription cancellation journeys
and identify friction that may make it unnecessarily difficult for users
to cancel a service. It aims to produce evidence-linked findings and map
relevant observations to CCPA-related considerations, while keeping the
final cancellation decision in the user's hands.
Important: ExitLens is an auditing and decision-support tool. It
does not automatically perform the final cancellation on a user's
behalf.
